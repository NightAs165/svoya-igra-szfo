# Своя игра: Северо-Западный федеральный округ

Публичная (статическая) версия игры «Своя игра» в духе SiGame: 4 категории, вопросы
на **100 / 250 / 500 / 1000** очков, таймеры, подсчёт очков игроков и особые
«удваиваемые» вопросы.

Всё работает без интернета, без сервера и без сборки — это обычные файлы
`HTML + CSS + JS`, которые можно открыть двойным щелчком или залить на любой
хостинг статических сайтов (GitHub Pages, Netlify, Vercel, Timeweb Cloud, свой nginx).

---

## Как запустить

### Вариант 1. Просто открыть файл

Откройте `index.html` в браузере. Всё будет работать (игра полностью на клиентской
части, никаких запросов к серверу).

### Вариант 2. Локальный сервер (рекомендуется для «живого» запуска)

В папке проекта лежит готовый скрипт:

```powershell
powershell -ExecutionPolicy Bypass -File .\start-server.ps1
```

Затем откройте в браузере **http://localhost:8765/**

### Вариант 3. Опубликовать для всех

1. Залейте папку (или только `index.html` + `assets/`) на любой статический хостинг.
2. Для GitHub Pages: создайте репозиторий, загрузите файлы, в настройках репозитория
   включите **Settings → Pages → Deploy from a branch → main / (root)**.
3. Ссылка вида `https://<user>.github.io/<repo>/` будет доступна всем.

## Как играть (правила для ведущего)

1. Ведущий выбирает ячейку на поле — открывается вопрос, и через **3 секунды**
   (на экране идёт отсчёт «Приготовьтесь!») запускается таймер:
   * **15 секунд** на вопросы за 100 и 250 очков;
   * **20 секунд** на вопросы за 500 и 1000 очков.
2. **Команда успела ответить** → ведущий жмёт «Показать ответ», ответ показывается,
   внизу появляется поле ввода **имени игрока** и суммы очков:
   * «Засчитать очки» — начисляет очки игроку (если такого игрока ещё нет, он создаётся);
   * «Ошибка» — снимает ровно столько очков, сколько можно было заработать за вопрос
     (−100 за вопрос на 100, −2000 за удвоенный вопрос на 1000);
   * «Без начисления» — закрыть вопрос без очков.
3. **Не успели ответить** → по истечении таймера ответ показывается автоматически,
   поле ввода имени **не появляется**, ячейка закрывается (красный значок ⏱) и больше
   не доступна для выбора.
4. **Особые вопросы** (1000 очков в категориях «А поребрик лучше!» и «Окно в Европу»): сначала на экране появляется
   карточка «Удвоить и ответить самому или отдайте вопрос любому игроку» — сам вопрос
   при этом **не показывается**. Ведущий выбирает условия (удвоить на 2000 очков или
   отдать игроку на 1000) и жмёт «Показать вопрос →». На поле эти вопросы никак не
   выделены — игроки не знают, где их ждать.
5. Счёт всех игроков виден справа, в любой момент можно нажать «Итоги» — выведется
   таблица результатов (её можно скопировать в чат). Когда сыграны все 16 вопросов,
   итоги открываются сами.
6. Прогресс сохраняется в `localStorage` браузера: если вкладку случайно закрыли,
   состояние игры и очки восстановятся. Кнопка «Новая игра» всё сбрасывает.

### Управление с клавиатуры

| Клавиши | Действие |
|---|---|
| `A` `S` `D` `F` | выбрать категорию (слева направо) |
| `1` `2` `3` `4` | выбрать цену вопроса (100 / 250 / 500 / 1000) и открыть его |
| `Enter` | показать ответ / засчитать очки |
| `Esc` | закрыть окно |

## Файлы

```
index.html              — разметка страницы
assets/styles.css       — оформление (тёмно-синяя «дженни»-тема)
assets/questions.js     — ВСЕ ВОПРОСЫ (здесь всё редактируется)
assets/app.js           — игровая логика: поле, таймер, очки, итоги
start-server.ps1        — локальный сервер для запуска (по желанию)
```

## Как править вопросы

Всё в файле **`assets/questions.js`**. Устройство простейшее:

```js
{
  points: 500,              // 100 | 250 | 500 | 1000
  q: 'Текст вопроса?',      // то, что увидит игрок
  a: 'Ответ',               // то, что увидит ведущий
  note: 'Комментарий ведущему (необязательно)',
  special: true             // перед вопросом покажется карточка «Удвоить и отдать»
}
```

Категории описаны в массиве `CATEGORIES` (их можно переименовать, переставить и
добавить новые — поле перестроится автоматически). Количество вопросов в категории
не обязано быть четыре — лишние ячейки просто не появятся, а при нехватке
стоимость придётся дописать в список `POINTS` в `assets/app.js`.

> Вопрос про **Obladaet** лежит в категории «Музыкальные имена на карте», 500 очков — его можно
> свободно заменить или убрать, ничего не сломается.

## Категории

1. **«А поребрик лучше!»** — питерский сленг (поребрик, пролёт и парадка, косяк) и особенности речи жителей других областей СЗФО.
2. **«Города-центры»** — столицы 11 субъектов СЗФО (Мурманск, Калининград, Петрозаводск, Нарьян-Мар…).
3. **«Окно в Европу»** — история основания Санкт-Петербурга, Пётр I, Северная война.
4. **«Музыкальные имена на карте»** — знаменитые рэперы региона (Оксимирон, Little Big, Obladaet, KREC).
